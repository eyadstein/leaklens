# AI layer performance

Generated by `python -m leaklens.bench_realworld`. Measurements are from the machine that ran the benchmark; reproduce them on yours before drawing conclusions.

> These timings were recorded with the Phase 6 model (threshold 0.50). The Phase 7 changes use the same model class and feature extractor — they add corpus cases, extraction guards, local attribution and a runtime gate — so the cost profile below is representative; the threshold is now 0.60 after the M6 rebuild. The Phase 6 real-world holdout was not re-scored for Phase 7 or M6.

## Environment

- Python: 3.14.3
- Platform: `Windows-11-10.0.26200-SP0`
- Model: `logistic_regression_balanced`, threshold 0.50; 1 candidate loaded from the artifact at request time (in-memory fit fallback; 11 compared when the benchmark is built)
- Model footprint: `{'coefficients': 108}`

- Artifact: `leaklens/ai/model.json`, plain JSON with schema `leaklens-ai-artifact-1`.

- Warm load in the same process: 1.16–1.27 ms.
- The cold fit avoided at request time: 1.339 s, the figure in the table below (measured on the
  benchmark machine, not alongside the load numbers above).

Measured on Python 3.14.3 / scikit-learn 1.9.1 / Windows 11 with `python -m leaklens.ai.artifact` followed by `artifact.load_artifact()`. A checked-in artifact whose corpus or feature catalogue digest no longer matches the code fails the artifact test until it is regenerated with that command.

## Reading these numbers

- These are single-machine measurements, not a guarantee.
- Training happens once per process; inference dominates repeated scans.
- Memory peaks include transient Python objects and are much larger than the model itself.
