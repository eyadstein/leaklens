## Parameters and limits

- Normalisation: NFKC, case fold, whitespace collapse; minimum 32 characters per document by default.
- Near duplicates: word 5-shingles, bottom-64 MinHash sketch, candidate generation from shared sketch values, Jaccard threshold 0.8.
- Bands with more than 64 members are skipped as boilerplate-like; exact duplicates are still reported by M2.
- Embedding similarity (M6) has no deterministic benchmark case because it depends on user-supplied vectors from an unpinned model.
- Recall is measured on this curated synthetic set only. Misses are listed above; a hard paraphrase is expected to miss at threshold 0.8.
