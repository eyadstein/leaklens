    What is live

    Filtering, expanding findings, switching fixtures, copying commands and replaying the recorded payload. Source-line highlighting follows the finding's real line number.

    Run the real scanner

    python -m pip install leaklens-ml, then copy any command from a result. The demo's fixtures are regenerated with python scripts/build_site.py.

    What it does not claim

    The replay is not a new scan and the browser has no backend. Trust scores are computed centrally from findings by the CLI; the demo replays that value instead of recalculating it.
