Limits are enforced by the backend and can differ from this displayed default after connecting.

What happens to the file

  • Parsed in memory for one request; never written to disk by LeakLens.
  • Size, row, column and cell limits are checked before detection.
  • The backend validates content, not the filename or MIME type.
  • No account, no tracking, no permanent dataset storage.
  • Errors are generic; stack traces and internal paths are not returned.

What is checked

  • Single-feature target leakage.
  • Identifier-like columns.
  • Categorical target leakage.
  • Group leakage risk.
  • Optional exact, feature-vector and near-duplicate split overlap.
  • Optional group and temporal boundary overlap.

Honest boundaries

This page does not claim that a scan ran when it did not. If the backend is missing, sleeping, rate-limited or timed out, you get an explicit error and a retry, never a fabricated score.

The GitHub Pages copy is not connected to a hosted backend unless a URL is supplied. The repository includes local and Render deployment instructions.
