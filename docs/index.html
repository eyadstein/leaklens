Three ways a pipeline lies to you

Coverage

What LeakLens looks for

More than thirty detector kinds across code and data. Each finding names the exact rule, the line or column, and a concrete fix. Severity reflects how confident the check is — not how scary the label sounds.

14 shown

target_leakage

A single feature alone predicts the label above the threshold (cross-validated ROC AUC, R² or balanced accuracy).

highdataset

categorical_target_leakage

A high-cardinality category is nearly pure with respect to the target, leaking the label through conditional entropy.

highdataset

id_like

A column is almost entirely unique values. It looks like an identifier and usually memorises rows instead of generalising.

mediumdataset

split_overlap

Exact row hashes appear in both train and test. The held-out score is partly a memory test.

highdataset

feature_overlap

Feature vectors match across the split while the label is ignored. Conflicting labels are reported as high, otherwise medium.

high / mediumdataset

near_duplicate_overlap

Rows match after lower-casing text, stripping whitespace and rounding numbers to four decimals. No fuzzy matching is claimed.

mediumdataset

preprocess_before_split

A scaler, encoder, imputer or transformer is fitted before train_test_split, so held-out rows shape the transform.

highcode

target_encode_before_split

Target means or aggregates are mapped into a feature before the split. The encoding has already seen the held-out labels.

highcode

feature_selection_before_split

SelectKBest, RFE or SelectFromModel chooses features using the full label before the split.

highcode

tuning_on_test_data

A search or manual loop fits on the test partition. The test set stops being held out.

highcode

cv_on_test_data

Cross-validation runs over the test partition, reusing it for training and validation.

mediumcode

temporal_split_shuffle

train_test_split shuffles a frame sorted by a time column, so future rows can enter training.

high / mediumcode

no_random_state

A split or sampler omits random_state, so every run produces different partitions and results are not reproducible.

lowcode

notebook_out_of_order_execution

Notebook cells have non-monotonic execution counts, so the saved output may not match the visible source order.

lownotebook

Also covered: group and entity overlap (--group), near-duplicate images across folders (leaklens images), notebook cell ordering, fit-on-eval-data, preprocessing outside CV, frequency encoding, fill/one-hot/temporal leakage, and repeated test-set reuse. Regression, not marketing

Get started

Three commands to a trust score

The base install handles CSV, JSON, dataset audits, code scans and every report format. Optional extras add Parquet, Excel, images, the model arena, and the API/UI.

Install

Python 3.10 or newer. No account, API key or network call required for a standard audit.

python -m pip install --upgrade leaklens-ml

Check the install

doctor verifies Python, the entry point, core dependencies and optional extras without reading secrets.

leaklens doctor

Audit something

Scan a dataset with its label, compare a split, or scan a whole Python project for pipeline leaks.

leaklens --scan . --explain

Dataset audit

Find target leakage, identifiers and overlap, then write a shareable report or a CI gate.

leaklens train.csv --target label --fail-under 80

Parse Python and notebooks for ordering, encoding, tuning and group-CV mistakes — no execution, no data upload.

Honest limits

What LeakLens does not do

A clean audit is evidence, not proof. These boundaries are deliberate and documented so you can judge a result instead of trusting a badge.

It does not execute your code

The code scanner parses source and notebooks. Data-dependent leaks that only appear at runtime, through dynamic dispatch or external state, can be missed.

Statistical checks use thresholds

Target leakage is a cross-validated score above a threshold (default 0.95). A strong but legitimate feature can be flagged for review; a weak leak can fall below it.

Duplicate checks are bounded and exact

Hashing is bounded to 50k rows for feature vectors and 20k for near-duplicates. Near-duplicate matching only normalises case, whitespace and four decimal places; it is not fuzzy matching.

It is not a privacy or PII scanner

LeakLens looks for label and split leakage in ML workflows. It does not classify personal data, redact columns, or replace a security review.

No automatic fixes

Every finding ships with a remediation hint, but the change is yours. Moving a transform into a pipeline can alter results and must be re-validated.

The browser demo is prerecorded

GitHub Pages serves static files, so the demo replays fixtures produced by the real scanners at build time. It never pretends to execute Python, and no backend is required.
