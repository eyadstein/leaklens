    * feat(scanner): flag target-encoding and group statistics before the split
    
    Flags features built from the target or from group statistics on all rows
    (issue #20), the pattern df.groupby(c)[y].transform('mean') computed
    before the split:
    
    - target_encode_before_split (high) when the groupby selection or the
      groupby keys touch the label the split divides (y from
      train_test_split(X, y), or the string column df['target']);
    - group_stat_before_split (medium) for other group statistics on all
      rows, whose held-out rows help build the feature.
    
    Both fire only before the first split, like the existing
    preprocess_before_split family. Fix hints added for both kinds, and four
    benchmark cases cover target-by-variable, target-by-column-name, a
    plain group statistic, and the clean after-split case.
    
    Co-authored-by: rahul05ranjan <11793455+rahul05ranjan@users.noreply.github.com>

    - bench: assigned-agg leak case + clean EDA summary case
    - tests: groupby over an X column stays medium; agg summary not
